# 车辆导入台

车辆导入台是 RIAutomobility 支持的自定义部件制作入口。它可以导入原生 Blockbench
`.bbmodel` 或由本模组生成的 `.riauto`，编辑车架、车轮和引擎参数，实时预览模型，
并导出分享文件或服务器内的部件物品。

[返回 Wiki 首页](Home.md) · [Blockbench 动画与 Molang](Blockbench-Animation-Molang.md)

## 合成

```text
铁锭    红石    铁锭
红石  工作台    红石
铁锭    铁锭    铁锭
```

合成结果为一个车辆导入台。右键方块即可打开编辑界面。

## 准备 `.bbmodel`

导入前请确认：

- 文件是 JSON 格式的原生 `.bbmodel`，大小不超过 32 MiB；
- 工程格式版本在 `4.10` 到 `5.0` 之间；
- 工程包含默认贴图，且所有贴图都保存为内嵌 PNG 数据；
- 模型用途与当前页面一致：外壳、轮子或引擎；
- 若使用骨骼动画，关键帧和 Molang 仅使用当前实现支持的功能。

编辑器会把选中的源文件复制到自己的本地缓存，再从副本生成预览和归档。源文件不会被
修改；在 Blockbench 中继续修改原文件后，需要重新导入才能刷新编辑器中的副本。

动画语法、查询量和限制见 [Blockbench 动画与 Molang](Blockbench-Animation-Molang.md)。

## 基本工作流

1. 在顶部选择“外壳”“轮子”或“引擎”页。
2. 点击“导入文件”，选择 `.bbmodel` 或 `.riauto`。
3. 等待状态显示预览已载入，然后设置名称和部件参数。
4. 在右侧三维预览中检查比例、位置、朝向和可见部件。
5. 选择“导出文件”或“导出物品”。

显示名长度必须为 1 到 80 个字符。内部资源 ID 由编辑器生成，不会因修改显示名而变化。
导出文件名以显示名为基础；若目标已存在，编辑器会使用带数字后缀的新文件名，不会覆盖
同名本地文件。

### 外壳页

外壳包含以下分页：

| 分页 | 用途 |
| --- | --- |
| 基础 | 名称、重量、引擎位置、隐藏引擎与基础外壳选择 |
| 轮位 | 管理每个轮位的位置、缩放、朝向、车轴与左右侧 |
| 座椅 | 管理座位和相机位置，并切换外部/第一人称预览；运行时最多使用前 8 个座位 |
| 碰撞 | 设置主体实体尺寸和附加物理碰撞箱 |
| 交互 | 设置非实体 OBB 交互盒、动作、触发方式与权限 |
| 附件 | 启用前后附件、设置安装位置及白名单/黑名单 |

交互盒的 JSON 语义、Molang 状态通道和调试方式见
[OBB 车辆交互盒](Vehicle-Interaction-Boxes.md)。
座位索引、驾驶权限和切换按键见 [车辆钥匙与多座位](Vehicle-Keys-and-Multi-Seat.md)。

### 轮子页

“基础”分页用于名称、物理尺寸、抓地、模型半径和宽度；“高级”分页用于模型整体
Y 轴旋转修正。外壳页中的每个轮位还可以单独设置缩放和朝向。

### 引擎页

引擎页用于名称、扭矩、速度和模型 Y 轴旋转修正。界面中的引擎动画开关只控制编辑器
预览，不会改变导出后引擎的性能。

## 导入 `.riauto`

选择 `.riauto` 时，编辑器会先验证归档，再读取其中唯一声明的车架、车轮或引擎组件，
恢复可编辑 BBModel 和贴图，并自动切换到对应页面。无效归档、缺少模型资源、包含不受
支持组件布局或无法恢复内嵌贴图的文件会被拒绝。

导入已有 `.riauto` 会恢复：

- 部件类型、显示名和参数；
- 可编辑的 `.bbmodel` 及内嵌贴图；
- 原作者信息；
- 车架的轮位、座位、碰撞箱、交互盒和附件配置。

`.riauto` 当前格式版本为 1。它是编辑器生成的交换归档，不承诺兼容手写或重新打包的
内部文件。

## 两种导出方式

### 导出文件

“导出文件”在客户端生成一个 `.riauto`，普通玩家也可以使用。默认目录是
`<游戏目录>/riautomobility/exports/`，也可以在保存对话框中选择其他目录。

归档包含运行时组件数据、BBModel、外置后的 PNG 资源和 `riauto.json` 元数据。构建过程
会重新验证模型和组件参数，但不会修改原始 `.bbmodel`。

### 导出物品

“导出物品”会先在客户端构建归档，再上传给服务器校验和发布。此操作要求权限等级 2。
成功后服务器会：

1. 将经过验证的 `.riauto` 发布到权威车包目录；
2. 重载自定义组件和清单；
3. 向在线客户端同步所需资源；
4. 在车辆导入台输出槽放入一个对应的外壳、轮子或引擎物品。

输出槽中已有物品时不能再次导出。请先取走物品；破坏车辆导入台时，输出槽内容会掉落。
单次上传上限为 64 MiB，上传会在 60 秒无活动后过期。

## 作者信息

- 从 `.bbmodel` 首次导出时，当前玩家名写入归档和物品作者；
- 导入已有 `.riauto` 后再次导出时，保留原作者，不会改成当前操作者；
- 作者名会显示在已知自定义部件的物品提示中；
- 作者字段最长 256 个字符，且不能包含控制字符。

## 常见问题

### 提示贴图未内嵌

在 Blockbench 中把每张工程贴图保存为内嵌 PNG，再重新保存并导入 `.bbmodel`。只提供
外部图片路径不足以生成可分享归档。

### 预览没有更新

编辑器使用导入时创建的缓存副本。修改原 `.bbmodel` 后，请再次点击“导入文件”。

### “导出物品”提示需要管理员权限

本地导出 `.riauto` 不需要管理员权限；安装到服务器并生成物品需要权限等级 2，
这是服务器端强制检查，不能由客户端界面绕过。

### 自定义部件显示为缺少资源

物品中的组件 ID 仍存在，但客户端没有收到与之匹配的车包资源。确认服务器权威目录中
仍有对应 `.riauto`，然后重新连接或让服务器完成一次车包同步。
