# 车辆导入台美术热重载包

该资源包只覆盖 RIAutomobility 车辆导入台的 GUI 美术资源。

## 文件

- `assets/riautomobility/textures/gui/vehicle_import_table.png`：512×300 完整背景。
- `assets/riautomobility/textures/gui/vehicle_import_selection.png`：512×300 选择预览页面背景。
- `assets/riautomobility/textures/gui/vehicle_import.png`：256×256 控件图集。
- 三张 PNG 各自对应的 `.png.mcmeta`：关闭模糊采样并启用边缘约束。

## 使用

1. 将整个文件夹放入 Minecraft 实例的 `resourcepacks` 目录。
2. 在资源包界面启用“RIAutomobility - 车辆导入台美术热重载包”。
3. 直接覆盖文件夹中的 PNG。
4. 回到游戏按 `F3+T` 重新加载资源。

不要修改图片尺寸、文件名或目录层级。控件图集的 Sprite 坐标必须保持不变。
