# RIAutomobility

**A Forge addon for Automobility with new vehicles, multi-seat support, and an in-game Blockbench vehicle editor.**

English | [中文](#中文)

## English

### Features

- Built-in double motorcars, quad motorcars, Lorry, DMC12, and Standard Formula vehicles
- Multi-seat layouts, custom hitboxes, cameras, and container support
- Vehicle Import Table for importing native Blockbench `.bbmodel` projects
- In-game parameter editing and live vehicle preview
- Shareable `.riauto` files generated by the editor
- Import shared `.riauto` files and export them as ready-to-use component items

### Dependencies

| Mod | Minimum Version |
|-----|-----------------|
| Forge | `47.1.x` |
| Automobility | `0.4.2+1.20.1-forge` |
| GeckoLib | `4.x` |

### Installation

1. Install Forge for Minecraft 1.20.1.
2. Put Automobility, GeckoLib, and RIAutomobility in the `mods/` folder.
3. Launch the game.

### Create And Share A Vehicle Component

1. Build the model in Blockbench and save it as `.bbmodel` with embedded PNG textures.
2. Import the project through the in-game Vehicle Import Table.
3. Adjust the component parameters and preview the result.
4. Export a `.riauto` file and share it.
5. Recipients import that `.riauto` file through the Vehicle Import Table and export an in-game item.

`.riauto` is an editor-generated exchange format. Handwritten component definitions and manually packaged RIAuto archives are not supported.

## 中文

### 功能

- 内置双座汽车、四座汽车、大运、DMC12 和标准方程式车辆
- 多座布局、自定义碰撞箱、摄像机与容器支持
- 通过车辆导入台导入原生 Blockbench `.bbmodel` 工程
- 在游戏内调整参数并实时预览车辆
- 通过导入台生成可分享的 `.riauto` 文件
- 导入别人分享的 `.riauto` 文件，并导出为可直接使用的部件物品

### 依赖

| 模组 | 最低版本 |
|------|----------|
| Forge | `47.1.x` |
| Automobility | `0.4.2+1.20.1-forge` |
| GeckoLib | `4.x` |

### 安装

1. 安装 Minecraft 1.20.1 对应的 Forge。
2. 将 Automobility、GeckoLib 和 RIAutomobility 放入 `mods/` 文件夹。
3. 启动游戏。

### 制作并分享车辆部件

1. 在 Blockbench 中建模，保存为包含内嵌 PNG 贴图的 `.bbmodel` 工程。
2. 使用游戏内车辆导入台导入工程。
3. 调整部件参数并检查预览效果。
4. 导出 `.riauto` 文件并分享。
5. 接收者通过车辆导入台导入 `.riauto`，再导出为游戏内物品。

`.riauto` 是由导入台生成的交换格式。不支持手写组件定义或手工打包 RIAuto 归档。
